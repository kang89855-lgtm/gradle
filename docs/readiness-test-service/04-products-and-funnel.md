# 19~25. 무료 결과 화면·결제 유도·상품 구성·리포트

# 19. 무료 결과 화면 예시

(예: 남성 / 결혼 고민 중 / 무료 10문항에서 ★ 2개 플래그 발생 시)

```
당신의 예비 결과

[유형 카드]
"외로움 결혼형"에 가까운 신호가 보입니다
— 결혼의 동기가 '이 사람'보다 '혼자인 상태의 종료'에
  가까울 때 나타나는 응답 패턴입니다.

[공개된 위험신호 2개]
⚠ 결혼을 외로움의 해결책으로 기대하는 경향 (문항 5)
⚠ 상대의 단점이 결혼 후 달라질 거라는 기대 (문항 9)

[블러 처리된 영역 — 미리보기]
🔒 감정 안정도       ██점
🔒 경제 현실도       ██점
🔒 가족 독립도       ██점
🔒 책임감 / 존중 / 현실 감각 / 대화 능력 / 위험신호 인식
🔒 추가 위험신호 ●개
🔒 결혼 전 반드시 나눠야 할 대화 질문 7개
🔒 지금 보완해야 할 점 3가지

※ 10문항 기준의 예비 결과입니다.
   60문항 정밀검사에서 유형이 바뀌는 경우가 있습니다.

[버튼] 전체 정밀 리포트 보기 — 9,900원
[작은 링크] 기본 결과만 먼저 볼래요 — 4,900원
```

- 플래그가 0개인 사용자에게는 위험신호 문구 대신: "예비 결과에서는 큰 위험신호가 없습니다. 다만 10문항으로는 경제·가족·대화 영역을 측정하지 못했습니다." → **정직하면서 결제 동기 유지.**
- 여성 안전 관련 경고 플래그 발생 시: 안전 점검 안내 + 상담 창구는 결제 없이 즉시 노출(윤리 원칙, `03` 참조).

# 20. 결제 유도 문구

**무료 결과 화면용 (조건부 노출 — 실제 응답 기준 충족 시에만)**
- 당신의 결과 중 일부만 공개되었습니다.
- 현재 응답에서 주의가 필요한 신호 ●개가 확인되었습니다. *(플래그 1개 이상일 때만)*
- 전체 리포트에서 감정·경제·가족·책임·존중·현실 감각·대화·위험신호 인식, 8개 항목의 점수를 확인할 수 있습니다.
- 커피 두 잔 값으로, 결혼 전 나의 위험신호를 확인하세요.
- 전체 60문항 정밀 리포트 보기

**결제 페이지용**
- 상담 한 번 가격의 1/10로, 상담 전에 알아야 할 것들을 먼저.
- 이 리포트에 포함된 것: 8개 항목 점수, 위험신호 카드, 결혼 전 대화 질문. 포함되지 않은 것: 상대방에 대한 평가, 결혼 가부 판정. *(신뢰 고지 = 환불 방어)*
- 지금까지 ○○,○○○명이 자신의 준비도를 확인했습니다.

**이탈 방지(결제 페이지 이탈 시 1회 노출)**
- 결과는 24시간 동안 보관됩니다. 내일 다시 봐도 괜찮아요. *(압박 대신 저장 프레임 — 스팸성 재촉 금지)*

**업셀(4,900원 결제자 결과 화면 하단)**
- +5,000원으로 정밀 리포트로 업그레이드 — 이미 응답한 문항은 그대로 이어집니다.

# 21. 4,900원 상품 — "기본 결과"

| 구성 | 내용 |
|---|---|
| 결과 유형 | 유형 1개 + 보조 성향 + 유형 해설(특징/강점/주의점) |
| 위험신호 | 상위 3개 카드 (신호 설명 + 왜 위험한지 1문단) |
| 등급 | S~D 등급 + 등급 의미 설명 |
| 업셀 | 정밀 리포트 +5,000원 업그레이드 버튼 |

- 역할: 첫 결제 장벽 제거. 단독 매출보다 업그레이드 발판.

# 22. 9,900원 상품 — "정밀 리포트" (주력)

| 구성 | 내용 |

| 맞춤 해설 | 유형 × 상태(연애/결혼/재혼/국제결혼/준비 중) 조합 해설 |

# 24. 결제 후 리포트 목차 (정밀 리포트 화면 구성)

1. 나의 연애·결혼 유형 (유형 카드 + 보조 성향)
2. 종합 등급과 의미
3. 8개 항목 점수 — ① 감정 안정도 ② 경제 현실도 ③ 가족 독립도 ④ 책임감 ⑤ 상대 존중도 ⑥ 현실 감각(결혼 환상도) ⑦ 현실 대화 능력 ⑧ 위험신호 인식
4. 나의 위험신호 카드 (발생 플래그 전체)
5. 결혼 전 반드시 대화해야 할 질문 7
6. 지금 보완해야 할 점 3가지 + 4주 플랜
7. (해당자) 국제결혼/재혼/부모동거 심화 해설
8. 3개월 후 다시 확인하기 (재검사 안내)
9. 이 리포트의 한계와 안내 (법적·윤리 고지)

# 25. PDF 리포트 예시 (심화 패키지, 20p 구성안)

```
p.1  표지 — "나의 연애·결혼 준비도 리포트" / 이름(선택) / 검사일 / 유형명
p.2  이 리포트를 읽는 법 + 한계 고지 (의료진단·법률상담 아님)
p.3  종합 결과 요약 — 등급, 유형, 레이더 차트
p.4~5  유형 심층 해설 — 특징 / 이 유형이 자주 겪는 갈등 장면 3가지
p.6~9  8개 항목 상세 — 항목당 반 페이지: 점수, 해설, 첫 번째 실천 행동
p.10~11  위험신호 카드 — 발생 신호별: 무엇이 / 왜 / 방치하면 / 지금 할 일
p.12  결혼 전 대화 질문 7 — 질문마다 "이 질문을 꺼내는 법" 한 줄
p.13~14  4주 보완 플랜 — 주차별 과제 (기록·대화·확인·재점검)
p.15~17  현실 체크리스트 40 — 경제/주거/가족/법·행정
p.18  (해당자) 상태별 심화 부록 요약
p.19  3개월 후 비교 페이지 (빈 칸 — 재검사 시 채워짐)
p.20  안내와 도움 창구 — 전문 상담기관, 공공 지원 연락처, 고지문
```

- 디자인 톤: 공포 마케팅형 빨간 경고 남발 금지. 신뢰감 있는 검진 리포트 톤(네이비/화이트 + 위험신호만 앰버).
