# 1. 서비스 전체 콘셉트

## 1-1. 한 줄 정의

**"결혼 전, 상대가 아니라 나를 먼저 검사하는 15분 자기진단 콘텐츠."**

- 카테고리: 심리 콘텐츠 커머스 (검사 → 리포트 → 심화 콘텐츠 → 선택형 상담)
- 형태: 모바일 웹 중심의 문항형 테스트 + 유료 리포트
- 핵심 문장(브랜드 슬로건 후보):
  - "좋은 사람을 만나기 전에, 내가 어떤 사랑을 반복하는 사람인지 먼저 알아야 합니다."
  - "상대를 검증하기 전에, 먼저 내가 사랑과 결혼을 감당할 준비가 되었는지 확인하세요."
  - "연애는 감정으로 시작되지만, 결혼은 준비로 지켜집니다."

## 1-2. 무엇이 아닌가 (포지셔닝 경계)

- 상대 뒷조사·신원조회·흥신소 서비스가 **아니다.**
- 의료적 심리진단·법률상담이 **아니다.**
- 결혼정보회사(매칭)가 **아니다.** — 오히려 매칭 전·후 어디서든 쓰는 "자기 점검 단계"로 포지셔닝.
- "국제결혼 서비스"가 **아니다.** 국제결혼은 상태 선택지 중 하나로만 노출되는 하위 심화 카테고리.

## 1-3. 타깃

| 세그먼트 | 상황 | 핵심 심리 |
|---|---|---|
| 남성 28~45 | 결혼 압박, 결혼정보/중개업체 이용 전후, 재혼·국제결혼 고민 | 책임, 경제, 부모 기대, 체면, 외로움, 실패 공포, 통제 위험 자각 |
| 여성 25~45 | 연애 중 확신 부족, 결혼 직전 불안, 재혼 고민 | 안전감, 존중, 감정 소모, 통제 피해 위험, 시댁, 경제 현실, 성급 결혼 |
| 공통 | "이 사람과 결혼해도 될까"를 검색하는 사람 전부 | 확신 부족 → 낮은 가격의 '판단 근거'에 지갑을 연다 |

## 1-4. 핵심 가치 제안

1. **상대 탓 이전에 나의 패턴** — 검사 결과가 "상대 평가"가 아니라 "내 준비도"라서 죄책감 없이 결제 가능.
2. **커피 두 잔 값의 판단 근거** — 상담(수십만 원)과 무료 심리테스트(신뢰 없음) 사이의 빈 가격대(4,900~19,900원)를 차지.
3. **성별·상태별 맞춤** — 남/여 분리 문항, 상태(연애·결혼·재혼·국제결혼·준비 중)별 심화 문항으로 "내 얘기다" 체감.
4. **위험신호 언어화** — 막연한 불안을 '통제위험', '성급진행', '헌신과다' 같은 이름 붙은 신호로 바꿔준다.

## 1-5. 서비스 흐름 (6단계 퍼널)

```
[1] 첫 화면 ── 남성으로 시작 / 여성으로 시작
        ↓
[2] 현재 상태 선택 ── 연애 중 / 결혼 고민 / 재혼 고민 / 국제결혼 고민 / 준비 중
        ↓
[3] 무료 테스트 10문항 (2~3분)
        ↓
[4] 무료 결과 ── 유형 이름 + 위험신호 1~2개만 공개 (블러 처리된 전체 리포트 미리보기)
        ↓
[5] 결제 ── 4,900 / 9,900 / 19,900 / 49,000원~
        ↓
[6] 정밀 리포트 ── 8개 항목 점수 + 위험신호 + 결혼 전 대화 질문 + 보완 플랜
```

## 1-6. 국제결혼 처리 원칙

- 랜딩·광고·브랜드에는 "국제결혼"을 노출하지 않는다.
- 2단계 상태 선택에서 "국제결혼 고민 중"을 고른 사용자에게만 추가 20문항 + 심화 해설(언어, 문화, 송금, 중개업체, 정착, 배우자 고립, 통제위험)을 연결한다.
- 표현 원칙: 신랑 보호와 신부 보호를 **함께** 다룬다. "속지 마라"가 아니라 "둘 다 안전한 결혼을 준비하라".

# 수익화 전략 (핵심 목표 달성 설계)

## A. 가격 사다리 (Price Ladder)

| 단계 | 가격 | 역할 |
|---|---|---|
| 무료 10문항 | 0원 | 유입·바이럴. 결과 일부만 공개해 결제 동기 생성 |
| 기본 결과 | 4,900원 | 심리 장벽 없는 첫 결제. "커피 두 잔 값" 프레임 |
| 정밀 리포트 | 9,900원 | **주력 상품.** 항목별 점수 + 맞춤 해설 + 결혼 전 질문지 |
| 심화 패키지 | 19,900원 | PDF 소장 + 체크리스트 + 대화 질문 50 + 위험신호 가이드 |
| 개인 해석 상담 | 49,000원~ | 선택형 고마진 상품. 전체 매출의 소수, 신뢰의 상징 |

- 결제 화면에는 3개만 노출(4,900 / **9,900 추천 뱃지** / 19,900) → 앵커링으로 9,900원 선택 유도.
- 4,900원 구매자에게 결과 화면에서 "+5,000원으로 정밀 리포트 업그레이드" 원클릭 업셀.

## B. 전환 퍼널 목표 수치 (보수적 모델)

| 구간 | 목표 전환율 |
|---|---|
| 광고 클릭 → 무료 테스트 시작 | 55% |
| 테스트 시작 → 완료 | 80% |
| 무료 결과 → 유료 결제 | 8~12% (콘텐츠 커머스 업계 상단) |
| 4,900원 → 9,900원 업그레이드 | 25% |
| 유료 → 심화 패키지 재구매 | 10% |
| 유료 → 상담 신청 | 2~3% |

**시뮬레이션 (월 방문 30,000 기준):** 완료 13,200명 × 결제 10% = 1,320건 × 평균객단가 9,500원 ≈ **월 1,250만 원** + 상담 30건 × 49,000원 ≈ 150만 원. 광고비(CPC 300원 가정) 약 900만 원 → 초기엔 손익분기 부근, 바이럴·재방문·SEO 비중이 오르면 마진 확대.

## C. 바이럴 루프 (CAC를 낮추는 장치)

1. **커플 초대 기능**: 결과 화면에서 "상대방 준비도도 궁금하다면 → 초대 링크 보내기". 상대가 완료하면 양쪽에 '커플 궁합 리포트' 할인 쿠폰. (상대 검증이 아니라 *상대도 자기진단*을 하는 구조 — 윤리 원칙 유지)
2. **결과 공유 카드**: 유형 이름 + 한 줄 설명만 담긴 이미지(점수 비공개) → SNS 공유 시 유입.
3. **쇼츠 콘텐츠 자산화**: 문항 1개 = 쇼츠 1개. "이 질문에 '매우 그렇다'면 통제위험 신호입니다" 형식.

## D. 재구매·LTV 장치

- 상태가 바뀌면 다시 산다: 연애 중 → 결혼 고민 → (재혼/국제결혼) 상태별 리포트가 별개 상품.
- 90일 후 리테스트 알림: "준비도는 변합니다. 3개월 전과 비교해보세요." (비교 리포트 4,900원)
- 시즌 캠페인: 명절 직후(파혼·갈등 검색 급증), 봄·가을 결혼 시즌, 연말.

## E. 제휴 채널 (B2B2C)

- 결혼정보회사·상담센터·웨딩플래너에 리포트 도매 제공(가입 전 자기점검 단계로 삽입).
- 지자체·다문화가족지원센터의 국제결혼 예정자 교육 프로그램에 심화 모듈 라이선스.

## F. KPI

- 북극성 지표: **주간 유료 리포트 열람 수**
- 보조: 무료→유료 전환율, 평균객단가, 커플 초대 수락률, 90일 재방문율, 환불률(<2%)

## G. 신뢰가 곧 전환율이다 (설계 원칙)

- 위험신호 문구는 **실제 응답 점수가 기준을 넘었을 때만** 노출한다. 모든 사용자에게 "위험신호가 감지되었습니다"를 일괄 노출하면 단기 전환은 오르지만 환불·신고·리뷰 악화로 채널이 죽는다. (전자상거래법상 거짓·과장 표시 리스크 회피 목적도 있음)
- 결제 전 "이 리포트에 포함된 것 / 포함되지 않은 것"을 명시 → 환불률을 낮추고 리뷰 품질을 올린다.
- 모든 결과 하단에 법적·윤리 고지(→ `06-legal-and-references.md`) 고정 노출.
