# 대사 깨짐 · 몰입 붕괴 보완 가이드

> 대상: 시댄스 국제결혼 러브스토리 계열 대본(라오스 시리즈, 학교(두 개의 언어) 등)
> 사용 시점: 초고 완성 직후 1회, 최종 확정 전 1회 — 총 2회 강제 통과
> 원본 점검표: `00-체크리스트-원본.md` (판정 기준은 이 문서를 따른다)

---

## 0. 용어 정의 — "대사가 깨진다"는 것

시청자가 대사를 듣다가 **"사람이 저렇게 말하지 않는데"** 하고 화면 밖으로 튕겨 나오는 순간.
원인은 거의 항상 아래 6가지 중 하나이며, 감정 부족이 아니라 **정보 설계 실패**다.

| # | 깨짐 유형 | 시청자가 느끼는 것 | 몰입 손실 지점 |
|---|---|---|---|
| D1 | 호칭·어미 불일치 | "둘이 무슨 사이지?" | 관계 인식 리셋 |
| D2 | 한쪽 인물 무음(서술로 대체) | "쟤는 왜 말이 없어?" | 인물 소멸 |
| D3 | 감정 선행(관계보다 대사가 빠름) | "벌써 결혼 얘기를?" | 개연성 붕괴 |
| D4 | 자기설명 대사(설명충) | "지금 나한테 설명하네" | 4의 벽 붕괴 |
| D5 | 격언·자막톤 남용 | "이건 대사가 아니라 자막" | 캐릭터 소멸 |
| D6 | 문구 재사용(작품 내/간 복붙) | "아까 그 말 또 하네" | 신선도 소멸 |

---

## 1. D1 — 호칭·어미 불일치 (가장 빈번)

**규칙**: 한 인물의 한 상대에 대한 말투는 **한 작품 내내 하나**. 바뀌려면 그 변화 자체가 사건이어야 한다.

말투 전환이 허용되는 경우는 단 3가지:
1. 관계 단계가 실제로 바뀐 직후 (호감 → 연인 → 부부)
2. 싸움/사과 등 감정 격변 씬 (그 씬 안에서만, 다음 씬 복귀)
3. 제3자(시부모·직장 상사)가 같은 공간에 있을 때의 격식 전환

### 교정 예시
```
✗ 여보, 이거 진짜 맛있는 거 아니에요?      ← 친밀 호칭 + 존댓말 어미
✓ 여보, 이거 진짜 맛있지 않아?
✓ (격식 유지가 필요하면) 당신, 이거 정말 맛있지 않아요?
```
```
✗ 오빠, 저 오늘 시장 다녀왔어요.
✓ 오빠, 나 오늘 시장 다녀왔어.
```

### 검수 방법
대본에서 한 인물 대사만 추출 → 호칭 목록과 어미 목록을 각각 뽑는다.
두 목록의 격식 수준이 섞이면 그 씬 번호를 전부 기록하고 일괄 교체한다.

## 2. D2 — 한쪽 인물 무음화

**증상**: 남주 대사는 큰따옴표 한국어인데, 여주는 `She explains that she misses home.` 같은 지문으로만 존재.
→ 화면에서 그 인물은 **말하지 않는 사람**이 된다. 국제결혼물에서 이 실수는 곧 "외국인 배우자 = 설명 대상" 이라는 인상까지 만든다.

**규칙**
- 모든 발화는 **한국어 직접 인용으로 먼저** 쓴다. 영어 ACTION 지문은 그 다음에 옮긴다.
- 한 씬에 두 인물이 있으면 **대사 비율 하한 30%**. 미달 씬은 대사 추가 또는 씬 통합.
- 침묵이 연출 의도라면, 침묵을 **행동으로** 쓴다. (`대답 대신 국그릇을 남편 쪽으로 민다`)

```
✗ ACTION: She explains that the soup is her mother's recipe.
✓ 쏨            엄마가 해주던 거야. 나 이거 없으면 밥 못 먹어.
   ACTION: She pushes the bowl toward him, watching his face.
```

## 3. D3 — 감정 선행

**규칙(40% 라인)**: 전체 분량의 40% 지점 이전에는 `결혼`, `평생`, `죽을 때까지`, `운명` 금지.

| 구간 | 허용 감정 어휘 |
|---|---|
| 0–20% | 호기심, 관찰 — "이름이 뭐야?", "그거 어떻게 하는 거야?" |
| 20–40% | 호감, 배려 — "먼저 먹어.", "오늘은 내가 데리러 갈게." |
| 40–70% | 미래 언급 가능 — "같이 살면 어떨까." |
| 70–100% | 약속·결심 — "평생 이렇게 살자." |

60씬 기준: 24씬 이전 무거운 단어 등장 시 전량 삭제 후 행동 묘사로 대체.

## 4. D4 — 자기설명 대사

인물이 자기 상황·감정·문화 배경을 **관객에게** 설명하면 몰입은 즉시 끊긴다.
정보는 **상대가 모르기 때문에** 나와야 한다.

```
✗ 나는 라오스에서 온 지 3년 됐고, 한국말이 아직 서툴러서 시장에서 늘 어려움을 겪어.
✓ (시장에서 가격표를 한참 본다)
   쏨          ...이거, 한 개에 얼마예요?
   상인        세 개 오천 원.
   쏨          한 개는요?
   상인        한 개는 안 팔아.
```
정보 전달이 꼭 필요하면 **질문하는 인물**을 씬에 넣어라. 설명은 대답의 형태일 때만 자연스럽다.

---

## 5. D5 — 격언·자막톤 남용

**규칙**: 한 작품당 격언식 대사 **최대 1회**, 그 1회는 클라이맥스에만 배치.
일상 씬(식사, 시장, 시댁 거실)에서는 전면 금지.

```
✗ 사랑은 국경을 넘는 법이지.
✓ (며느리가 끓인 국을 한 숟갈 먹고) 어머니   ...짜다. 근데 계속 먹게 되네.
```
추상명사(사랑·행복·인연·희생)가 대사에 들어가면 일단 삭제하고, 그 감정을 **동작 1개 + 짧은 말 1줄**로 바꾼다.

---

## 6. D6 — 문구 재사용

**규칙**: 동일/유사 문형은 한 작품 내 1회. 시리즈 간 재사용도 금지(시청자가 같은 채널에서 연속 시청함).

검사 명령 예시:
```bash
# 작품 내 반복
grep -o '이것도 내가 다 했어' 대본.md | wc -l
# 시리즈 간 반복 (대사 줄만 추출해 중복 검출)
grep -h '^\s*[가-힣]\{1,4\}\s\{2,\}' *.md | sed 's/^\s*[가-힣]\{1,4\}\s\{2,\}//' \
  | sort | uniq -d
```
중복 검출된 문장은 최소 1곳을 다른 표현으로 교체하고, 교체 이력을 `02-교정로그.md`에 남긴다.

## 7. 몰입 유지 구조 규칙 (대사 밖 원인)

대사가 정상인데도 몰입이 깨진다면 아래를 본다.

- **갈등 즉시 봉합 금지**: 갈등 발생 → 해소까지 최소 3씬. 1~2씬 봉합은 시청자에게 "문제가 없었다"로 읽힌다.
- **리액션 숏 확보**: 웃긴 씬·충격 씬 뒤 최소 1씬은 여운. 바로 다음 사건으로 컷하지 않는다.
- **엔딩 자동화 금지**: 전통혼례 + 카메라 정면 메시지 조합은 시리즈 반복 사용 금지. 관통 모티프(사물)로 닫는다.
- **말투 변화 = 사건**: 반말로 처음 말하는 순간, 이름을 처음 부르는 순간은 각각 독립 씬으로 확보한다.

## 8. 최종 검수 절차 (확정 전 필수)

1. 대사만 추출한다.
   ```bash
   grep -n '^\s*[가-힣]\{1,4\}\s\{2,\}' 대본.md > /tmp/lines.txt
   ```
2. D1 검사 — 인물별 호칭/어미 격식 혼용 여부
3. D2 검사 — 씬별 인물 대사 비율 30% 하한
4. D3 검사 — 40% 지점 이전 `결혼|평생|운명|영원` 검색, 히트 0 확인
   ```bash
   grep -nE '결혼|평생|운명|영원' 대본.md
   ```
5. D4 검사 — 3줄 이상 연속 단일 인물 대사 = 설명 의심 구간
6. D5 검사 — 추상명사(`사랑|행복|인연|희생`) 대사 내 등장 수, 1 이하 확인
7. D6 검사 — 위 uniq -d 결과 0건 확인
8. 모든 항목 통과 후에만 확정. 미통과 항목은 `02-교정로그.md`에 씬 번호와 함께 기록.
