## A. 대사 작성 체크리스트 (호칭·어미·분량)

- [ ] **호칭-어미 일치 검사**: "여보/오빠/자기" 같은 친밀 호칭을 쓰면서 "~예요/~아니에요?" 존댓말 어미를 같이 쓰지 않았는가?
  → 부부·연인은 원칙적으로 반말 또는 편한 말투로 통일. 존댓말이 필요하면 호칭도 격식체로 맞출 것.
- [ ] **여성 주인공 대사 실존 여부**: 남자 주인공 대사만 한국어로 직접 인용되고, 여자 주인공 대사는 "explains", "answers" 같은 영어 서술로만 처리된 장면이 있는가?
  → 모든 발화는 예외 없이 한국어 직접 인용으로 먼저 쓰고, 그다음 영어 지문(ACTION)에 옮겨 넣을 것. 대사 없는 서술 문장 금지.
- [ ] **관계 진행 속도와 대사 내용 일치**: 만난 지 얼마 안 된 시점(1~5씬 이내)에 "결혼하면", "평생" 같은 무거운 단어가 등장하지 않는가?
  → 초반부는 호기심·호감 표현까지만. 결혼·미래를 언급하는 대사는 최소 중반(전체 분량의 40% 지점) 이후로 이동.
- [ ] **문구 재사용 검사**: "이것도 내가 다 했어" 류의 자기 과시 문장이 같은 작품 안에서 2회 이상, 또는 다른 작품에서 반복 사용되지 않았는가?
  → 검색으로 확인: 대본 전체에서 동일 문장/유사 문형이 2회 이상 나오면 최소 1곳은 다른 표현으로 교체.
- [ ] **격언체 남용 검사**: 일상 대화 장면(가족·시댁 등)에 속담식·잠언식 문장이 반복 등장하지 않는가?
  → 한 작품당 격언식 대사는 1회로 제한. 나머지는 일상어로.

## B. 반복 패턴(구조) 체크리스트 — 신규 대본 착수 전 필수

- [ ] 이 작품의 **드라마 엔진**(사건)이 무엇인지 한 문장으로 쓸 수 있는가? (감동·절약·응원만으로는 통과 불가)
- [ ] **역할 구도**가 "여성 적극·애교/남성 수줍음" 고정형에서 최소 1가지 이상 다른가?
- [ ] **갈등 처리 방식**이 1~2씬 내 즉시 봉합이 아니라 최소 3씬 이상 끌고 가는가?
- [ ] **장소**가 강변/노을/델타/전통시장 클리셰에서 벗어났는가?
- [ ] **엔딩**이 전통혼례+카메라 정면 메시지 자동 반복이 아닌가?
- [ ] **관통 모티프**(사물)가 기존 작품들과 겹치지 않는가?

## C. 웃음/행복감 확보 체크리스트 (코미디 요소가 필요한 작품)

- [ ] 웃음 포인트가 "사건 → 오해/실수 → 반전"의 3단 구조를 갖추고 있는가?
- [ ] 웃긴 상황 뒤에 최소 1씬은 리액션/여운 숏이 배치되어 있는가? (바로 다음 장면으로 컷 금지)
- [ ] 유적/문화 설명 장면에 웃긴 방해 요소(끼어드는 동물, 떨어지는 물건 등)가 하나라도 있는가?
- [ ] 코미디 담당 캐릭터가 있다면, 이 캐릭터가 "웃겨주는 역할"이 아니라 실제로 "웃긴 행동을 하는 역할"인가?
- [ ] 갈등이 웃음으로 이어지지 않고 곧장 감동/로맨스로만 수습되지 않는가?

## 사용 방법

1. 새 대본 초안 작성 전 → **B 항목**부터 체크 (구조 확정)
2. 대사 초안 작성 후 → **A 항목** 전체 검사 (한국어 대사만 따로 뽑아서 확인)
3. 코미디/밝은 톤 프로젝트인 경우 → **C 항목** 추가 검사
4. 체크 안 된 항목은 대본 최종 확정 전 반드시 수정
