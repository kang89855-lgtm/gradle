# 05. 운영 프로세스 — 등록·주문·CS·반품

> 멀티채널(기존 마켓 + 쿠팡 + 11번가 + G마켓·옥션) 운영은 "루틴화"가 전부다. 매일 같은 시간에 같은 순서로 처리하면 1인이 상품 수백 개를 돌릴 수 있다.

---

## 1. 하루 운영 루틴 (1인 기준, 약 2~4시간)

```
[오전 - 주문/발주 처리, 30~60분]
 1. 채널 4곳 신규 주문 수집 (통합 툴 도입 전엔 채널별 순회)
 2. 위탁 상품 → 도매처에 발주 (도매처 마감시간 전 필수! 보통 오전~정오)
 3. 사입 상품 → 송장 출력·포장·집하 예약
 4. 어제 발주 건 송장번호 회수 → 각 채널에 운송장 입력

[오후 - CS/재고, 30~60분]
 5. 문의·리뷰 답변 (24시간 내 응답 원칙)
 6. 도매처 품절·단종 공지 확인 → 전 채널 품절 처리 (가장 중요한 단일 작업)
 7. 반품·교환 접수 처리

[저녁 - 성장 작업, 60~120분]
 8. 신규 상품 리서치·등록 (하루 5~10개 목표)
 9. 판매 데이터 확인, 가격·키워드 조정
```

## 2. 상품 등록 표준 (채널 공통)

등록 1건마다 지킬 체크리스트:

- [ ] 상품명: 키워드 조합 규칙 적용 (→ `06-marketing.md`), 채널별 글자수 제한 내
- [ ] 카테고리: 실제 카테고리 정확히 (잘못 넣으면 검색 노출 자체가 안 됨)
- [ ] 대표이미지: 흰 배경·텍스트 없음 (채널 규정), 1000px 이상
- [ ] 옵션: 도매처 옵션과 1:1 매핑 — 임의로 만들면 발주 사고 발생
- [ ] 상품정보제공고시: 공란 없이 (원산지·제조자·인증번호)
- [ ] 배송정보: 도매처 실제 출고지·출고 소요일 그대로 (하루 늦게 잡는 게 안전)
- [ ] 마진 계산 완료 (순마진 15%+, → `04-pricing-and-margin.md`)

## 3. 품절 동기화 — 계정을 지키는 최우선 업무

- 위탁판매 최대 리스크 = **팔렸는데 도매처 품절 → 판매자 귀책 취소 → 채널 페널티.**
- 방어책:
  1. 도매처 품절 알림(문자·API)을 켜고, 매일 오후 품절 목록을 전 채널에 반영.
  2. 재고 연동 지원 소싱처(도매매 등) 상품 비중을 높인다.
  3. 취소가 발생하면 페널티 낮은 사유 처리 + 고객에게 선제 연락·사과 (분쟁 예방).
  4. 품절 잦은 도매처는 분기마다 정리 — 도매처도 성과로 관리한다.

## 4. CS 템플릿 (기존 마켓에서 쓰던 것 재활용 + 채널 톤 맞춤)

| 상황 | 응대 원칙 |
|---|---|
| 배송 문의 | 송장번호 + 택배사 조회 링크 즉시 제공. "확인해보겠습니다"로 끝내지 않는다 |
| 단순 변심 반품 | 규정대로 접수 (7일 내). 반품 배송비 안내를 명확히 — 분쟁 대부분이 여기서 발생 |
| 하자·오배송 | 사진 요청 → 도매처 확인과 **무관하게** 고객에겐 즉시 교환/환불 확정 통보 (책임 주체는 판매자) → 도매처와는 별도 정산 |
| 악성 리뷰 | 감정 대응 금지. 사실관계 정정 + 해결 의지만 공개 답변, 보상 협의는 비공개로 |

## 5. 반품 처리 흐름 (위탁)

```
고객 반품 신청 → 채널에서 접수 확인 → 도매처에 반품 접수 (도매처 반품지 주소로 회수)
→ 도매처 검수 → 환불 확정 → 채널 환불 처리
```

- 도매처마다 반품 규정(왕복 배송비·검수 기준)이 다르다. **소싱 전에 반품 규정을 확인**하고, 반품비가 과도한 도매처 상품은 마진에 그만큼 가산한다.

## 6. 주간·월간 루틴

| 주기 | 작업 |
|---|---|
| 주 1회 | 채널 판매자센터 공지 확인 (수수료·정책 변경), 상품별 실현 마진 점검 |
| 주 1회 | 계정 지표 확인 — 취소율·지연배송률·응답률. 경고 수준이면 원인 상품 즉시 조치 |
| 월 1회 | 채널별 정산 리포트 다운로드 → 손익 집계 시트 갱신 (→ 세무 증빙 겸용) |
| 월 1회 | 사입 전환 후보 선정 (월 20건+ × 2개월 기준), 부진 상품 100개 삭제·교체 |
| 분기 1회 | 도매처 성과 평가(품절률·배송속도·반품처리), 통합관리 툴 비용 대비 효과 점검 |

## 7. 확장 단계의 자동화·외주

| 시점 | 도입 |
|---|---|
| 상품 300개+ / 채널 3개+ | 통합관리 툴 (등록·재고·주문 연동, → `01-platforms.md` 4-2) |
| 일 주문 30건+ | 사입 상품 3PL(물류대행) 검토, 로켓그로스·스마일배송 검토 |
| 월 순익 300만+ | CS 외주(채팅 대행) 또는 파트타임, 본인은 소싱·데이터에 집중 |
