# 06. 마케팅 — 검색 노출·광고·리뷰

> 오픈마켓 마케팅의 8할은 "검색 결과에 내 상품이 뜨게 하는 것"이다. 광고는 그 다음이고, 리뷰는 전환율의 엔진이다.

---

## 1. 상품명 키워드 SEO (비용 0원, 효과 최대)

### 1-1. 상품명 조합 공식

```
[브랜드/수식어] + [핵심 키워드] + [세부 속성] + [용도/타깃 키워드]

예) 스텐 주방 수납선반 2단 싱크대 조리대 정리 선반
    └ 핵심: "주방 수납선반"  └ 속성: 2단, 스텐  └ 용도: 싱크대·조리대 정리
```

수칙:

- **대표 키워드 1개 + 세부(롱테일) 키워드 2~4개**로 구성. 검색량 도구(아이템스카우트·판다랭크 등)에서 실제 검색되는 조합만 사용.
- 동일 단어 반복·특수문자·과장 문구("최저가", "1위")는 채널 어뷰징 필터에 걸린다.
- 카테고리와 키워드가 어긋나면 노출 제외 — 키워드가 속한 카테고리를 도구로 확인 후 등록.
- 채널별 글자수·금칙어 규정이 다르므로 채널별로 상품명을 따로 관리한다 (통합 툴의 채널별 상품명 필드 활용).

### 1-2. 검색 랭킹을 올리는 실제 변수

| 변수 | 액션 |
|---|---|
| 최근 판매량(판매지수) | 초기엔 롱테일 키워드로 소량이라도 판매를 만들어 지수를 쌓는다 |
| 클릭률(CTR) | 대표이미지가 절반이다 — 같은 도매 이미지라도 크롭·배치 다르게 |
| 전환율 | 상세페이지 상단 3초 안에 "무엇·왜·구성" 전달, 리뷰 노출 |
| 상품정보 충실도 | 고시정보·속성값 공란 없이 (랭킹 가점 요소) |
| 계정 신뢰도 | 취소율·배송지연 관리 (→ `05-operations.md`) |

### 1-3. 채널별 포인트

- **쿠팡**: 검색 SEO보다 **아이템위너 확보**(가격·배송·평점)가 우선. 위너 못 잡는 상품은 광고 금지.
- **11번가·G마켓·옥션**: 전통 검색 랭킹 — 상품명 SEO와 판매지수 축적이 그대로 통한다. 롱테일 수확 채널.
- **기존 마켓**: 이미 쌓인 판매지수·리뷰가 있으므로 신상품 테스트와 시딩(초기 판매 만들기)에 사용.

## 2. 유료 광고 — 데이터 쌓인 후, 소액부터

### 2-1. 원칙

1. **광고는 "이미 팔리는 상품"의 증폭기다.** 안 팔리는 상품에 광고를 부으면 적자만 증폭된다.
2. 시작 시점: 자연 판매 월 10건+ 상품이 5개 이상 생겼을 때.
3. 예산: 일 1~2만 원 → ROAS(광고수익률) 확인 후 증액. **ROAS 손익분기 = 1 ÷ 순마진율** (순마진 20%면 ROAS 500% 이상이어야 이익).

### 2-2. 채널별 광고 상품

| 채널 | 시작 추천 |
|---|---|
| 쿠팡 | 매출최적화 광고(자동)로 시작 → 수동 키워드 광고로 비효율 키워드 제외 |
| 11번가 | 포커스 클릭(CPC) — 검증 키워드에만 |
| G마켓·옥션 | 파워클릭(CPC) — ESM에서 통합 운영 |

- 주 1회 광고 리포트에서 **전환 없는 키워드 제외**가 광고 운영의 90%다.

## 3. 리뷰 — 전환율의 엔진

- 목표: 주력 상품 리뷰 30개+ / 평점 4.5+.
- 합법적 확보 수단:
  1. 채널 공식 리뷰 적립금 프로그램 활용 (비용은 마진 계산에 반영).
  2. 구매 고객 대상 리뷰 요청 메시지 (채널 규정 내에서).
  3. 체험단 운영 시 **"협찬·대가성 제공" 표기 필수** — 미표기는 표시광고법 위반 + 채널 제재.
- 금지: 가족·지인 구매(어뷰징 탐지), 리뷰 구매, 경쟁사 비방 리뷰. 적발 시 계정 정지 리스크가 이익보다 항상 크다.

## 4. 프로모션 캘린더

| 시기 | 액션 |
|---|---|
| 매월 채널 행사 (월간 특가·쿠폰전) | 판매자센터 제안 코너에서 참여 신청 — 마진 계산 후 참여 여부 결정 |
| 11월 (십일절·빅스마일데이) | 연중 최대 트래픽 — 3분기부터 재고(사입 상품)·쿠폰 준비 |
| 설·추석 | 선물세트 묶음 구성 (같은 도매처 상품 조합) |
| 시즌 전환기 (3월·9월) | 계절 상품 등록은 시즌 6~8주 전 (판매지수 쌓일 시간 필요) |

## 5. 외부 유입 (선택, 3개월차 이후)

- 블로그·카페: 상품 사용기형 콘텐츠 → 검색 유입. 대가성 표기 준수.
- 쇼츠·릴스: 상품 시연 15초 영상 → 프로필 링크로 스토어 연결. 1일 1개 축적형.
- 외부 유입은 채널 랭킹에도 긍정 신호가 되지만, **본업(등록·품절관리·CS)이 흔들리면 하지 않는다.** 우선순위는 항상 검색 SEO > 리뷰 > 광고 > 외부 유입.
