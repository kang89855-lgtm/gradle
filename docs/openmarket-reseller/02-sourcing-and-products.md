# 02. 소싱 채널과 상품 선정

> 리셀 사업의 성패는 "어디서 얼마에 가져와서" × "무엇을 고르느냐"에서 대부분 결정된다.

---

## 1. 소싱 채널

### 1-1. 국내 위탁판매 (무재고 — 1단계 기본)

주문이 들어오면 도매처가 소비자에게 직배송. 재고·물류 부담 0.

| 채널 | 특징 |
|---|---|
| 도매매 (domeme) | 위탁판매 표준. 상품DB 대량 다운로드, 오픈마켓 연동 지원 |
| 오너클랜 | 상품 수 많고 API/엑셀 연동 지원 |
| 온채널 | 제조사·수입사 직거래 비중 높음 |
| 도매토피아 | 생활·주방 카테고리 강함 |

체크포인트:
- **배송 속도와 품절 알림 정확도**가 상품 가격보다 중요하다 (채널 계정 점수와 직결).
- 같은 상품을 수백 명이 파는 구조이므로, 상품 자체보다 **키워드·옵션 구성·묶음**으로 차별화한다.
- 상세페이지 이미지 사용권 범위를 확인한다 (도매처 제공 이미지는 대부분 판매 목적 사용 허용, 외부 이미지 무단 사용 금지).

### 1-2. 국내 사입 (2단계 — 검증 상품 전환용)

| 채널 | 특징 |
|---|---|
| 도매꾹 | 국내 최대 도매 장터. 소량 사입 가능 |
| 동대문·남대문·화곡동 유통단지 | 직접 발품. 의류·잡화·생활용품 현금 사입 |
| 제조사 직거래 | 위탁으로 검증된 상품의 제조사에 직접 연락 — 최저 원가 |

- 사입 전환 기준: **월 20건 이상 × 2개월 연속 판매 + 반품률 5% 미만** 상품만.
- 첫 사입은 1~2주 판매분만. "싸게 준다고 박스로" 받는 순간 재고 리스크 시작.

### 1-3. 해외 소싱 (선택 — 마진 극대화, 난이도 상승)

- 1688(알리바바 내수몰)·타오바오: 국내 도매가의 30~60% 수준. 배송대행지·검품·통관 필요.
- 관세(과세가격 기준), KC인증 대상 여부(→ `03-legal-and-tax.md`)를 **주문 전에** 확인.
- 시작은 인증 불필요·파손 위험 낮은 경량 잡화부터.

### 1-4. 브랜드 상품 리셀 소싱 (주의 영역)

- 정식 유통 경로: 브랜드 총판·대리점 계약, 도매몰의 정품 유통분, 병행수입.
- **정품 증빙(세금계산서·수입신고필증) 없이 브랜드 상품을 올리지 않는다.** 상표권자 신고 한 번이면 계정이 정지될 수 있다. 상세 리스크는 `03-legal-and-tax.md`.

## 2. 카테고리 선정 기준

초보 리셀러 추천 필터 — 아래 5개를 모두 통과하는 카테고리부터:

1. **단가 1만~5만 원** — 저단가는 마진 절대액이 안 나오고, 고단가는 반품 리스크가 크다.
2. **비계절성** — 연중 수요 (계절상품은 데이터 쌓인 뒤에).
3. **비인증 대상** — KC·식품·화장품 인허가 없는 상품 (생활잡화, 주방, 수납, 문구, 차량용품 등).
4. **낮은 파손·변질 위험** — 유리·액체·식품 제외.
5. **브랜드 무관 구매** — 소비자가 브랜드를 따지지 않는 실용재 (검색어가 "주방 수납선반"이지 "OO브랜드 선반"이 아닌 것).

기존 마켓에서 이미 팔리는 카테고리가 있다면 **그 인접 카테고리부터 확장**한다 (구매 고객층·소싱처·CS 노하우 재사용).

## 3. 상품 선정 — 데이터 기반 5단계

```
[1] 키워드 발굴: 아이템스카우트·판다랭크·셀러라이프 등에서
    "검색량 대비 상품 수(경쟁강도)" 낮은 키워드 추출
        ↓
[2] 검색량 필터: 월 검색량 1,000~30,000 구간
    (너무 크면 대형 셀러 전장, 너무 작으면 수요 없음)
        ↓
[3] 경쟁 확인: 해당 키워드 상위 노출 상품의 리뷰 수 확인
    — 상위권이 리뷰 수백 개면 후발 진입 어려움, 리뷰 수십 개면 기회
        ↓
[4] 소싱 매칭: 도매처에서 해당 키워드 상품 검색 → 도매가 확보
        ↓
[5] 마진 검증: 채널별 수수료 반영 마진 계산 (→ 04 문서 공식)
    — 순마진 15% 미만이면 탈락, 등록하지 않는다
```

- 하루 10개씩 검증하면 한 달에 등록 후보 200~300개가 나온다. **선정은 기계적으로, 감정 없이.**
- 기존 마켓 판매 데이터가 있으므로: 이미 팔린 상품의 **연관 키워드**(함께 검색되는 단어)부터 파면 성공률이 높다.

## 4. 피해야 할 상품 (마진과 무관하게 배제)

- 위조 가능성 있는 브랜드품, 정품 증빙 불가 상품
- KC 미인증 전기용품·유아용품 (병행이든 뭐든 인증 없으면 판매 불법)
- 식품·건강기능식품·화장품·의약외품 — 별도 영업신고 전까지 금지
- 칼·에어건 등 판매 제한 품목, 리콜 이력 상품
- 도매처 재고 변동이 심한 상품 (품절 취소 = 계정 점수 하락)
- 판매가 대비 부피·무게가 큰 상품 (배송비가 마진을 먹는다)
