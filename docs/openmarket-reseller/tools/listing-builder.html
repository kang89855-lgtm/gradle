리셀 등록안 생성기 (묘목)

소싱처(심폴 등) 페이지에서 상품명과 가격을 복사해 붙여넣으면, 상호가 제거된 등록용 상품명과 등록 판정 기준(필요 최소 시세)을 일괄 생성한다.
기준: 판매가는 시장 정상가 고정 · 수수료 14% · 이익 35% · 운반비 5,000원 → 필요 최소 시세 = (매입가 + 5,000) ÷ 0.51

3. 등록안

#등록용 상품명 (상호 제거)매입가필요 최소 시세시세 확인 후 판정

판정 방법: 각 상품을 쿠팡·네이버쇼핑에서 검색해 실제 팔리는 정상가를 확인한다. 정상가 ≥ 필요 최소 시세면 그 정상가로 등록(이익 35% 확보), 미달이면 등록하지 않는다.
등록 시 주의: 상품정보제공고시의 생산자/공급자 칸에는 실제 생산 농원을 기재해야 한다(법정 항목). 품종보호 등록 품종 여부를 소싱처에 확인할 것. 소싱처의 사진·상세문구를 무단 복사하지 말 것.
