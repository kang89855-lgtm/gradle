# 1. 사업 콘셉트

## 1-1. 한 줄 정의

**"재고 없이 시작해서, 데이터로 검증된 상품만 사입으로 전환하는 오픈마켓 리셀 사업."**

- 카테고리: 전자상거래 소매업 (오픈마켓 입점 판매)
- 초기 형태: **위탁판매(무재고)** 중심 → 판매 데이터 확보 후 잘 팔리는 상품만 사입 전환
- 핵심 원칙: 상품을 고르는 감이 아니라 **키워드 수요 데이터와 마진 계산**으로 의사결정한다.

## 1-2. 리셀 사업 모델 4가지 비교

| 모델 | 방식 | 초기 자본 | 마진율(순) | 핵심 리스크 |
|---|---|---|---|---|
| **위탁판매** | 도매 사이트 상품을 내 스토어에 등록, 주문 오면 도매처가 직배송 | 0~50만 원 | 5~15% | 마진 얇음, 같은 상품 파는 경쟁자 다수, 품절 동기화 |
| **사입 판매** | 도매처·동대문·1688에서 미리 매입 후 직접(or 3PL) 발송 | 300만 원~ | 20~40% | 재고 리스크, 물류 부담 |
| **해외 구매대행** | 주문 후 해외(1688·타오바오 등)에서 구매해 배송대행지 경유 발송 | 50~100만 원 | 15~30% | 배송 7~14일, 관세·통관, KC인증, CS 난이도 |
| **브랜드 리셀(병행수입 포함)** | 정품 브랜드 상품을 확보해 재판매 | 상품별 상이 | 변동 큼 | **상표권·가품 분쟁, 판매 자격 제한** — 진입 전 법적 검토 필수 (→ `03-legal-and-tax.md`) |

## 1-3. 추천 진입 경로 (단계형)

```
[1단계] 위탁판매로 시작 (재고 0)
    ├─ 목적: 돈 벌기보다 "등록→노출→판매→CS" 전체 사이클 학습 + 판매 데이터 수집
    └─ 상품 100~300개 등록, 월 순익 목표 30~100만 원
        ↓
[2단계] 데이터 검증된 상품 사입 전환
    ├─ 기준: 월 20건 이상 꾸준히 팔리고 반품률 낮은 상품
    └─ 사입하면 원가 20~40% 절감 → 가격 경쟁력 + 마진 동시 확보
        ↓
[3단계] 자체 상세페이지·묶음 구성으로 차별화
    └─ 같은 상품이라도 검색 키워드·사진·구성이 다르면 딴 상품이 된다
        ↓
[4단계] (선택) 자체 브랜드(PB)화 또는 카테고리 전문몰
```

## 1-4. 무엇이 아닌가 (경계)

- 한정판 스니커즈 되팔기 같은 **단건 프리미엄 리셀이 아니다.** (플랫폼 정책·매점매석 논란 영역)
- 가품·이미테이션 판매가 **아니다.** 정품 여부가 불확실한 소싱처는 마진이 좋아도 배제한다.
- 브랜드 공식 홈페이지 문구·이미지를 무단 복사하는 판매가 **아니다.** (저작권·상표권 침해)

# 2. 수익 시뮬레이션 (보수적 모델)

## 위탁판매 3개월 차 가정

| 항목 | 수치 |
|---|---|
| 등록 상품 수 | 300개 |
| 판매 발생 상품 비율 | 10% (30개) |
| 월 총 주문 | 150건 |
| 평균 판매가 | 25,000원 |
| 월 매출 | 375만 원 |
| 상품 원가(도매가+배송비) | 약 65% = 244만 원 |
| 플랫폼 수수료 (평균 8% 가정) | 30만 원 |
| 광고비 | 20만 원 |
| **월 순이익** | **약 80만 원 (순마진율 ~21%… 위탁 치고 낙관적, 실제 10~15% 구간이 흔함)** |

- 위탁 단계의 진짜 산출물은 순익이 아니라 **"어떤 키워드의 어떤 상품이 팔리는가"라는 데이터**다.
- 사입 전환 시 동일 매출 기준 순이익이 1.5~2.5배로 뛰는 구조를 목표로 한다.

## KPI

- 북극성 지표: **주간 순이익 (매출 아님)**
- 보조 지표: 상품별 노출→클릭률(CTR), 클릭→구매 전환율, 반품률(<5%), 품절 취소율(<1%), 리뷰 평점(4.5+)
- 매출이 늘어도 순마진율이 10% 아래로 내려가면 광고비·수수료 구조를 먼저 점검한다.

# 3. 90일 로드맵

| 기간 | 할 일 | 산출물 |
|---|---|---|
| 1주차 | 사업자·통신판매업 신고 상태 점검(기존 마켓 신고 정보로 충족되는지 확인, → `03-legal-and-tax.md`) → 쿠팡 WING 입점 신청 → 11번가·ESM(G마켓·옥션) 입점 신청 | 3개 채널 판매 가능 상태 |
| 2주차 | 기존 마켓 판매 데이터 분석(잘 팔린 상품·키워드), 도매 소싱처 확장, 채널별 마진 재계산 | 채널별 등록 후보 100개 |
| 3~4주차 | 기존 마켓 상품을 쿠팡·11번가·ESM에 이관 등록 (채널별 상품명 SEO 적용, → `06-marketing.md`) | 멀티채널 오픈 |
| 2개월차 | 등록 300개 확대, 채널별 판매 데이터 비교, 멀티채널 통합관리 툴 도입 검토, CS 템플릿 정착 | 채널별 판매 데이터 |
| 3개월차 | 잘 팔리는 상품 5~10개 사입 전환 검토, 쿠팡 광고 소액 테스트(일 1~2만 원) | 주력 상품 라인 |

# 4. 실패 패턴 체크리스트 (선배 셀러들의 무덤)

- [ ] 마진 계산 없이 "남들이 파니까" 등록 → 팔릴수록 적자 (→ `04-pricing-and-margin.md` 공식 필수)
- [ ] 통신판매업 신고 전에 판매 시작 → 과태료
- [ ] KC인증 대상(전기·유아·생활용품)인지 모르고 판매 → 판매중지·처벌 리스크
- [ ] 도매처 품절을 스토어에 반영 안 함 → 주문취소 누적 → 스토어 지수 하락
- [ ] 브랜드 로고 박힌 상품을 정품 증빙 없이 판매 → 상표권 신고로 계정 정지
- [ ] 한 플랫폼에만 의존 → 정책 변경 한 방에 매출 0
