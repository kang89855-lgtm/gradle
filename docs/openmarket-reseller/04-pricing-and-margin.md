# 04. 가격 책정과 마진 계산

> 리셀러가 망하는 첫 번째 이유는 "팔릴수록 손해인 가격"이다. 등록 전에 반드시 계산한다.
> **기준 조건: 수수료 14% · 목표 수익률 35% · 운반비 5,000원** (아래 1-1 참고). 목표 미달 상품은 등록하지 않는다.
> 같이 있는 `tools/margin-calculator.html`을 브라우저로 열면 아래 공식을 바로 계산할 수 있다 (기준 조건이 기본값으로 입력되어 있음).

---

## 1. 마진 계산 공식

```
순이익 = 판매가
        - 상품 원가 (도매가)
        - 매입 배송비 (위탁: 도매처 택배비 / 사입: 입고 운임 안분)
        - 판매 배송비 부담분 (무료배송이면 판매자 부담 전액)
        - 플랫폼 수수료 (판매가 × 채널 수수료율 — 배송비에도 수수료가 붙는 채널 주의)
        - 포장·부자재 (사입 시)
        - 광고비 안분 (광고 쓰는 상품이면 건당 광고비 = 광고비 ÷ 판매건수)
        - 반품 충당금 (판매가의 1~2% 권장)

순마진율 = 순이익 ÷ 판매가 × 100
```

## 1-1. 기준 운영 조건 (확정값) — 정상가 기준 모델

이 사업의 가격 책정 기준값:

| 항목 | 값 |
|---|---|
| 판매가 | **정상 판매가 (시장 시세)** — 시세보다 올려 팔지 않는다 |
| 마켓 수수료율 | 판매가의 **14%** |
| 목표 이익 | 판매가의 **35%** |
| 운반비 (건당) | **5,000원** |

판매가를 시세에 고정하므로, 공식은 판매가 역산이 아니라 **매입가 상한 역산**이 된다:

```
판매가(정상가)의 구성:  수수료 14% + 이익 35% + (원가 + 운반비) 51%

최대 허용 매입가 = 정상가 × 0.51 − 5,000
```

**즉, "정상가의 절반에서 운반비를 뺀 값"보다 싸게 소싱해야 등록한다.** 정상가별 조견표:

| 정상 판매가 | 수수료 (14%) | 이익 (35%) | 최대 허용 매입가 |
|---|---|---|---|
| 19,900 | 2,786 | 6,965 | **5,100** |
| 27,900 | 3,906 | 9,765 | **9,200** |
| 29,900 | 4,186 | 10,465 | **10,200** |
| 39,900 | 5,586 | 13,965 | **15,300** |
| 49,900 | 6,986 | 17,465 | **20,400** |

- 이 구조에서 등록/탈락 판단은 가격이 아니라 **소싱**에서 일어난다: 시세는 건드리지 않고, 상한보다 싸게 소싱되는 상품만 등록한다.
- **판매는 마케팅으로 만든다** — 가격을 내려 경쟁하는 대신 시세를 유지하고, 검색 SEO·광고·리뷰(→ `06-marketing.md`)로 노출과 전환을 확보하는 전략. 이때 광고비는 이익 35%에서 차감되므로 **광고 손익분기 ROAS = 1 ÷ 0.35 ≈ 286%** — 이보다 낮은 캠페인은 중단한다.
- 반품 충당금(기본 1.5%, 묘목 3~5%)을 반영하면 허용 매입가가 그만큼 내려간다 (계산기에서 자동 반영).

### 검증 예시 — 도매가 9,000원, 판매가 27,900원 (수수료 14%, 운반비 5,000원)

| 항목 | 금액 |
|---|---|
| 판매가 | 27,900 |
| 도매가 | -9,000 |
| 운반비 | -5,000 |
| 플랫폼 수수료 (14%) | -3,906 |
| **순이익** | **9,994 (35.8%)** |

→ 등록 가능. 광고를 붙이면 건당 광고비만큼 줄어드는 것까지 감안해 판단한다.

## 2. 채널별 가격 정책

- **수수료가 다르면 최저 마진 판매가도 다르다.** 기준 수수료 14%로 역산하되, 실제 카테고리 수수료가 그보다 낮은 채널에서는 같은 판매가에서 마진이 더 남는 구조로 둔다 (기준을 보수적으로 잡는 효과).

```
최소 판매가 역산:
판매가 = (도매가 + 배송비 + 고정비) ÷ (1 - 수수료율 - 목표순마진율)
```

- 단, **쿠팡은 타 채널 판매가를 모니터링한다** — 쿠팡 가격이 타 채널보다 눈에 띄게 높으면 아이템위너·노출에서 불리해질 수 있다. 채널 간 가격 차는 배송비 포함 실결제가 기준 ±5% 안에서 관리한다.
- 가격 맞추기가 어려우면 채널별로 **구성(1+1, 수량, 사은품)을 다르게** 해 비교 자체를 어렵게 만든다.

## 3. 배송비 전략

| 방식 | 장점 | 단점 | 추천 |
|---|---|---|---|
| 무료배송 (판매가에 포함) | 노출·전환 유리, 필터 통과 | 저단가 상품에서 마진 압박 | 15,000원 이상 상품 기본값 |
| 유료배송 (2,500~3,000원) | 저단가 상품 마진 방어 | 전환율 하락 | 1만 원 미만 상품 |
| 조건부 무료 (3만 원 이상) | 객단가 상승 유도 | 위탁판매는 합배송 불가한 경우 많음 — 도매처 확인 필수 | 같은 도매처 상품 다수일 때 |

- 위탁판매 함정: 소비자가 내 스토어에서 2개 주문해도 도매처가 다르면 **택배가 2건 = 배송비 2번 내가 부담.** 조건부 무료배송은 같은 도매처 상품끼리만 설계한다.

## 4. 가격 인하 경쟁 대응 수칙

1. **따라 내리지 않는다** — 최저가 경쟁은 자본 큰 쪽이 이기는 게임. 순마진이 목표(35%)를 크게 밑돌기 시작하면 그 상품은 접고 다음 상품을 찾는다.
2. 대신 바꾸는 것: 상품명 키워드(다른 수요 공략), 옵션 구성, 묶음 수량, 사진.
3. 경쟁자가 소수이고 판매량이 검증됐다면 **사입 전환으로 원가를 깎아** 같은 판매가에서 마진을 회복하는 게 정석.

## 5. 손익 관리 루틴

- 주 1회: 판매 상품별 실현 마진 확인 (수수료 명세 기준, 계산 가정과 실제가 다른지 검증).
- 월 1회: 채널별 손익 집계 — 매출·수수료·광고비·반품비. **채널별 순이익**이 나와야 채널 전략(→ `01-platforms.md` 4-3)을 조정할 수 있다.
- 반품률 5% 넘는 상품은 마진과 무관하게 원인 분석 후 개선 불가 시 판매 중단 (반품 1건이 판매 3~4건 이익을 지운다).
