# 01. 입점 채널 — 쿠팡 · 11번가 · G마켓·옥션

> 전제: 자체 마켓(기존 스토어)은 이미 운영 중. 이 문서는 신규 입점할 3개 채널의 절차·수수료·정산·운영 특성과 멀티채널 전략을 다룬다.
> 수수료율·정산 주기는 카테고리와 정책 개정에 따라 달라진다. **입점 시점에 각 채널 판매자센터 공지로 재확인할 것.**

---

## 1. 채널별 한눈 비교

| 항목 | 쿠팡 (마켓플레이스) | 11번가 | G마켓·옥션 (ESM PLUS) |
|---|---|---|---|
| 판매자센터 | WING | 셀러오피스 | ESM PLUS (지마켓·옥션 통합) |
| 입점비 | 무료 | 무료 | 무료 |
| 판매수수료(대략) | 카테고리별 약 4~11% | 카테고리별 약 7~13% | 카테고리별 약 7~13% |
| 기타 비용 | 월 서버 이용료(일정 매출 이상 시, 약 5만 원대) | 없음 | 없음 |
| 정산 주기 | 느린 편 (주정산/월정산, 최장 수십 일. 빠른정산 조건부 제공) | 구매확정 후 익영업일~수일 | 구매확정 후 익영업일~수일 |
| 트래픽 성격 | 국내 최대급 구매 트래픽, 가격·배송 속도 민감 | 검색·기획전·십일절 등 프로모션 | 4050 비중 높음, 스마일클럽/카드 프로모션 |
| 배송 옵션 | 판매자배송(일반) / 로켓그로스(쿠팡 물류 위탁) | 판매자배송 | 판매자배송 / 스마일배송(물류 위탁) |
| 노출 로직 핵심 | 아이템위너(동일 상품 중 가격·조건 최적 판매자가 노출 독식) | 검색 랭킹 + 광고 | 검색 랭킹 + 광고 |
| 리셀러 관점 난이도 | 중 (아이템위너 경쟁 심함) | 하 | 하 |

## 2. 채널별 핵심 이해

### 2-1. 쿠팡 — 트래픽은 최대, 규칙은 가장 독특

- **아이템위너 구조**: 같은 상품을 여러 판매자가 팔면 상품 페이지는 하나로 합쳐지고, 가격·배송·평점이 가장 좋은 판매자가 '아이템위너'로 매출 대부분을 가져간다.
  - 리셀러 시사점: **남들과 똑같은 위탁 상품은 가격 치킨게임에 빨려든다.** 옵션 구성·묶음 수량을 다르게 하거나, 위너를 못 잡을 상품은 등록만 해두고 광고비를 쓰지 않는다.
- **로켓그로스**: 쿠팡 물류센터에 입고하면 로켓 배지가 붙어 전환율이 크게 오른다. 단, 입출고·보관 수수료가 추가되므로 **회전 빠른 검증 상품만** 입고한다. 위탁(무재고) 상품은 불가 — 사입 전환 단계에서 검토.
- 정산이 느리므로 **사입 자금 회전 계획에 정산 지연을 반드시 반영**한다. (매출이 커질수록 묶이는 현금이 커진다)
- 입점: WING 가입 → 사업자등록증·통신판매업신고증·통장 사본 제출 → 승인 후 판매.

### 2-2. 11번가 — 무난한 표준 오픈마켓

- 검색 기반 노출이라 **상품명 키워드 SEO**(→ `06-marketing.md`)가 그대로 통한다.
- 십일절(11월) 등 대형 프로모션 참여 시 트래픽 스파이크. 기획전·쿠폰 제안 메일을 활용.
- 아마존 글로벌 스토어와 한 앱에 있어 해외직구 수요 고객이 섞여 있다.
- 입점: 셀러오피스 가입 → 서류 제출(쿠팡과 동일 서류) → 승인.

### 2-3. G마켓·옥션 — 계정 하나(ESM PLUS)로 두 마켓 동시 운영

- **ESM PLUS 마스터 계정 하나로 G마켓·옥션에 동시 등록/주문관리**가 된다. 실질적으로 "1회 등록 = 2개 채널 노출"이라 리셀러 가성비가 좋다.
- 스마일클럽(유료 멤버십) 고객 대상 쿠폰·적립 프로모션이 강해, 생활용품·중장년 타깃 상품이 잘 맞는다.
- 스마일배송(물류 위탁)은 로켓그로스와 같은 논리로 사입 단계에서만 검토.
- 입점: ESM PLUS 가입 → G마켓·옥션 각각 판매자 정보 연결 → 서류 제출 → 승인.

## 3. 입점 순서와 서류 (1주차 실행 체크리스트)

공통 필요 서류 — 한 번 준비하면 3곳 모두 사용:

- [ ] 사업자등록증 (업태: 도매 및 소매업 / 종목: 전자상거래 소매업)
- [ ] 통신판매업 신고증 — **기존 마켓 개설 때 이미 신고했다면 재신고 불필요.** 단, 신고 당시 적어낸 판매 방식·도메인 범위 확인 (→ `03-legal-and-tax.md`)
- [ ] 사업자 명의 통장 사본
- [ ] (법인이면) 법인 등기부등본, 인감증명서

실행 순서:

1. **쿠팡 먼저 신청** — 승인 대기가 있을 수 있어 가장 먼저 넣는다.
2. 같은 날 **11번가 + ESM PLUS 신청** — 서류가 동일하므로 하루에 다 넣을 수 있다.
3. 승인 기간(수일) 동안 기존 마켓 판매 데이터에서 이관할 상품 후보를 추린다.

## 4. 멀티채널 운영 전략 (기존 마켓 + 신규 3채널)

### 4-1. 원칙

1. **기존 마켓의 판매 실적이 검증한 상품부터 이관한다.** 신규 채널에서 밑바닥부터 테스트하지 말 것 — 이미 가진 데이터가 최대 자산이다.
2. **가격은 채널별 수수료를 반영해 따로 계산한다.** 모든 채널에 같은 판매가를 쓰면 수수료 높은 채널에서 마진이 사라진다. 단, 쿠팡은 타 채널 대비 눈에 띄게 비싸면 아이템위너·다이내믹 프라이싱에서 불리해지므로 밸런스를 잡는다.
3. **재고(위탁이면 도매처 품절)는 채널 전체에 동기화한다.** 한 채널 품절 미반영 → 주문취소 → 판매지수 하락이 가장 흔한 자멸 패턴.

### 4-2. 통합관리 툴

채널 3~4개 × 상품 수백 개부터는 수기 관리가 불가능하다. 2개월차에 도입 검토:

- 대량 등록·재고 연동·주문 통합 수집: 샵플링, 이지어드민, 셀메이트, 플레이오토 등 (기능·요금 비교 후 1개 선택)
- 위탁 소싱처(도매매·오너클랜 등)가 제공하는 채널 연동 기능이 있으면 우선 활용 — 무료이거나 저렴하다.

### 4-3. 채널별 역할 분담 (예시)

| 채널 | 역할 |
|---|---|
| 기존 마켓 | 검증 실험실 — 신상품 테스트, 단골·재구매 관리 |
| 쿠팡 | 볼륨 채널 — 검증 상품의 매출 극대화, 사입 전환 후 로켓그로스 |
| 11번가 | 검색 SEO 채널 — 키워드 롱테일 수확, 프로모션 참여 |
| G마켓·옥션 | 커버리지 채널 — ESM 1회 등록으로 노출면 2배, 중장년 타깃 |

## 5. 채널 리스크 관리

- **계정 건강 점수 관리**: 쿠팡(주문이행률·정시배송), 11번가·ESM(판매자 평가지표) 모두 취소율·지연배송에 페널티. 위탁 단계에서는 **도매처 품절·배송지연이 곧 내 점수 하락**이므로, 응답 빠르고 재고 정확한 도매처만 남기고 정리한다.
- **정산 리듬 분산**: 쿠팡(느림) + 11번가·ESM(빠름) 조합은 현금흐름 상호 보완이 된다. 사입 자금은 빠른 정산 채널 매출 기준으로 계획한다.
- **정책 변경 대응**: 수수료·노출 로직은 통보 후 바뀐다. 판매자센터 공지를 주 1회 확인하는 루틴을 운영 체크리스트(→ `05-operations.md`)에 포함.
